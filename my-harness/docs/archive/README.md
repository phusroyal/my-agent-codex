# Archive

This folder stores historical material that is useful for reference but is **not the current source of truth** for GoalFlow.

Use it for:
- earlier full-design documents;
- precursor notes and external SCM notes;
- superseded versions that may still explain how a design choice developed.

Do not implement directly from files in this folder unless a current document explicitly points here.

Current scientific definitions live in `../scientific-design/`.
Current implementation specifications live in `../implementation/`.
Current execution instructions live in `../work-packages/` and `../exec-plan/`.
