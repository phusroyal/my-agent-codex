# Scientific Design

This folder defines **what the experiment means**.

It contains the scientific questions, causal model, experimental environment, causal quantities, hypotheses, neural questions, and rules for interpreting result patterns.

Files:

1. `01-scope.md` — research question, scope, and intended chain of evidence.
2. `02-causal-model.md` — variables, structural equations, and intervention semantics.
3. `03-environment.md` — controlled procurement environment and experimental interventions.
4. `04-causal-quantities.md` — checkpoint-local, historical, plan, history, state, and event comparisons.
5. `05-hypotheses.md` — falsifiable hypotheses and the behavioral-to-mechanistic branching logic.
6. `06-neural-mechanism.md` — representation availability, causal neural intervention, downstream transmission, and cross-condition comparison.
7. `07-result-interpretation.md` — evidence required for common result patterns and the limits of each conclusion.

These files explain **why a comparison is scientifically meaningful and what a result supports**.

Exact schemas and runtime procedures belong in `../implementation/`.

Execution order belongs in `../work-packages/`.

Current progress belongs in `../exec-plan/`.
