# Active Execution Plans

This folder contains execution plans that are currently in progress.

Keep only active work here. Each file should make it possible to answer quickly:
- what is being implemented or run now;
- what is already complete;
- what is blocked;
- what happens next;
- which commits or experiment runs correspond to the work.

Name files after the work package or bounded task, for example:

```text
wp0-renderer.md
wp0-checkpoint-replay.md
wp1-pilot-launch.md
```

When the work is complete, move the file to `../completed/` rather than rewriting it as a new specification.
