# Completed Execution Plans

This folder stores finished execution plans.

Completed plans are a record of what was actually implemented or run. They are useful for reconstructing:
- implementation history;
- blockers that were resolved;
- commits associated with a completed task;
- experiment runs and outputs;
- deviations from the original plan.

Do not treat these files as the current implementation specification. The current source of truth remains in `../../implementation/`, `../../work-packages/`, and the executable configs.
